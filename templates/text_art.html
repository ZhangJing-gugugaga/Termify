文字艺术

把一段文字或一句描述，变成能在任何终端显示的 ASCII 艺术字。

FIGlet 精选字体，选择作品的整体字形。

AI 模式

AI 从描述中提取文字与字体，本地精确渲染，快且稳定。

「AI 生成」由你自部署的 LLM 驱动——Key 与内容不经过任何第三方页面。三步开通：

  1. 跑一个 OpenAI 兼容服务：ollama serve（本地）或注册智谱 / DeepSeek 拿 API
  2. 点下方预设自动填入，再补上 API Key（Ollama 无需 Key）
  3. 保存，回来点「AI 生成」

详细部署文档见 GitHub README；API Key 只保存在服务端（data/llm_config.json），不会下发到浏览器，也不进日志。
